# gpjs-ui

The main package for [gpjs-ui](https://github.com/tom96da/gpjs-ui), an
ultra-lightweight, Webview-free desktop application framework powered by
GPUI and QuickJS. It provides the framework-agnostic JS API that talks
directly to the native host bridge (`globalThis.__gpjsui_native__`) —
framework bindings such as `@gpjs-ui/vue` (and later `@gpjs-ui/react`) are
built on top of it.

This package is currently a placeholder — implementation has not started.
